# 共脑智营 CommonBrain Ops

面向中小服务业的可审计、多模型、多智能体运营操作系统。

> 让企业 AI 用得起、管得住、查得到、随时可换模型。

## 项目简介

CommonBrain Ops 将企业微信、飞书和 Web 等工作入口，与岗位智能体、企业知识库、共享事实层、多模型路由、权限审计、健康检查和备份恢复组合成一个可部署的企业 AI 工作中枢。

它解决的不是“再做一个聊天机器人”，而是中小企业在 AI 落地时遇到的连续性问题：

- 不同 Agent 对同一件事记忆不一致；
- 模型配额、价格、延迟和故障不可控；
- 企业知识没有来源引用和权限边界；
- 自动化只能演示，缺少评测、监控、审计和恢复；
- 员工无法在已有工作入口中自然使用 AI。

## 核心架构

```text
企业微信 / 飞书 / Web
          │
统一网关、身份与权限
          │
岗位 Agent 与业务工作流
          │
共享事实层 ─ 企业知识库 ─ 来源引用
          │
CommonBrain Router
  ├─ 国产云模型 / 超算互联网
  ├─ 其他兼容模型
  └─ 本地开源模型
          │
审计日志 / 健康检查 / 备份恢复 / Eval 闸门
```

## 代表性能力

### 共享事实层

统一记录事件、决定、任务状态、来源和更新时间，让不同 Agent 在不同入口中引用同一事实，而不是各自维护互相冲突的记忆。

### 动态模型路由

根据任务类型、可用额度、历史可靠性、延迟和预算选择模型；在超时、限额或供应商故障时进行熔断和受控降级。

### 可审计工作流

关键工具调用、来源、人工确认、模型和资源消耗进入审计记录；高风险动作默认需要人工确认。

### 面向小企业的可部署性

优先适配企业已经使用的消息入口，并提供环境变量示例、健康检查、备份和恢复流程，降低没有专职 AI 团队的企业使用门槛。

## 开源与权属边界

本项目可基于 Hermes Agent、OpenClaw 及其他开源组件进行集成，但不会把上游代码、上游测试数量或第三方 Skills 作为自研成果。发布前会在 `docs/third-party-notices.md` 中列出版本、来源和许可证；自有模块包括共享事实协议、渠道适配、角色工作流、模型路由、评测、审计和运维资产。

## 隐私与安全原则

- 公开 Demo 使用合成数据或经授权的脱敏数据；
- API Key 只通过环境变量或密钥管理器提供；
- 不把客户姓名、电话、会员标识和内部路径提交到公开仓库；
- Agent 工具按角色最小授权，高风险动作人工确认；
- 记录模型、来源、工具结果和资源消耗；
- 每月执行恢复、越权和提示注入测试。
