# 申报用项目介绍

## 项目名称

共脑智营 CommonBrain Ops——面向中小服务业的可审计多智能体运营操作系统

## 核心痛点

中小企业使用 AI 时普遍存在入口分散、知识无法共享、多个 Agent 输出不一致、模型成本和额度不可控、敏感数据缺少权限管理，以及系统只能演示但无法长期稳定运行等问题。共脑智营将企业微信/飞书等工作入口、岗位智能体、企业知识库、共享事实层、多模型路由、权限审计、健康检查和备份恢复整合为统一的企业 AI 工作中枢。

## Agent/AI 驱动成果

项目已完成多渠道企业消息接入、岗位角色智能体体系、企业知识库和共享事实层，并构建动态模型路由、可靠性/延迟评估、预算控制、故障熔断和受控降级能力。同时建立了健康检查、事件记录、备份恢复和评测机制。目前已在辽宁一家约 3 家门店、20–30 名员工的连锁生活服务企业开展内部试点，用于知识检索、运营协作、员工培训和营销流程支持。
