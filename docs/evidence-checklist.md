# 公开发布与审核证据检查表

## 发布前必须完成

- [ ] 确认项目负责人、主体和公开联系方式
- [ ] 创建 GitHub/Gitee 仓库并统一项目名称
- [ ] 补充 `third-party-notices.md`
- [ ] 删除所有 Key、Cookie、内部 IP 和客户数据
- [ ] 将真实业务样例全部脱敏或替换为合成数据
- [ ] 标明“已有结果 / 内部试点 / 计划目标”三种状态
- [ ] 补一份可运行 README 和环境变量示例
- [ ] 至少提供一个真实截图、Notebook 或 Demo

## 审核材料

- [ ] 一页纸项目介绍
- [ ] 架构图
- [ ] 30–50 个脱敏任务评测
- [ ] 模型、Token、延迟和错误记录
- [ ] 权限、提示注入和越权测试
- [ ] 备份恢复演练记录
- [ ] 内部试点授权或匿名证明
- [ ] 三个月里程碑与资源预算

## 公开披露边界

- 不公开客户姓名、电话、会员号、聊天原文；
- 不公开密钥、Cookie、内网地址、完整生产配置；
- 不把开源底座和第三方技能写成自研；
- 不把目标指标写成已完成指标；
- 不虚构用户数、收入、融资、科研合作或交易。
